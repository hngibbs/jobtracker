https://jobtracker-06ms.onrender.com

## GitHub Repository

---

## Description
This is a full-stack Spring Boot web application that allows users to track job applications. Users can create, update, delete, and view job applications with details such as company, role, status, location, salary, and follow-up dates.

---

## Features
- Create new job applications
- View all applications
- Edit existing applications
- Delete applications
- Filter by status and location
- Search by company or role
- Responsive and styled user interface

---

## Technologies Used
- Java
- Spring Boot
- Spring Data JPA
- Thymeleaf
- H2 Database (development)
- PostgreSQL (production via Neon)
- Render (deployment)
- Docker
